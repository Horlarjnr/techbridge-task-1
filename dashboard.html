      API Documentation

      The dashboard talks to a Node.js + Express backend at http://localhost:3000. Task data is stored in backend/data/tasks.json.

      MethodEndpointPurpose
      GET/api/tasksGet all tasks
      GET/api/tasks/:idGet one task
      PUT/api/tasks/:idUpdate a task's status
      POST/api/tasksAdd a new task (optional)
      DELETE/api/tasks/:idDelete a task (optional)
      GET/api/healthCheck that the backend is running

      Statuses: completed, progress, notstarted

      Update example: PUT /api/tasks/7 with the body {"status": "completed"}
